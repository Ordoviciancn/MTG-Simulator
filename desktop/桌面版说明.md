# Windows 桌面版

`pnpm desktop:build` 构建客户端和服务端，输出 `release/MTG Simulator-win32-x64/MTG Simulator.exe`。这是包含 Electron/Chromium/Node 的真实 Windows 程序；分发时保留整个目录，不能单独复制 exe。构建输出不会加入 Git。`pnpm desktop:dev` 用同一打包结构启动开发桌面窗口。

当前桌面程序自带网页资源与 Node 房间服务，**尚未捆绑 Forge 和 JDK**。首次启动需选择已运行 `scripts/构建Forge核心.ps1` 的 MTG-Tabletop 项目根目录，以及 JDK 17 或更高版本目录。系统还需要 Git 用于校验 Forge 固定提交；卡图通过 Scryfall 在线加载。Forge 全量规则卡数据沿用所选运行环境，不代表所有机制或卡牌已通过本客户端验收。

配置保存在 Electron 用户数据目录的 `runtime.json`，可通过菜单“对局 → 运行环境位置”查看。设置 `FORGE_WORKSPACE_ROOT` 和 `JAVA_HOME` 可覆盖路径。运行环境需保持可写，因为目前每局 Forge 的隔离用户目录创建在该项目 `.local-tools` 下。移动项目后重新选择目录；更新源码桥接代码会影响之后新建的对局。

程序每次分配独立本机端口，关闭程序时终止自己启动的房间服务。不会占用或结束 8787–8789 的浏览器服务。退出丢失内存中的对局；Java 崩溃恢复和断点续局尚未完成。“对局 → 新窗口”可供第二位本机玩家加入同一房间。当前桌面入口仅绑定本机，不支持直接由另一台电脑连接；远程大厅后续另行实现。

渲染窗口开启沙箱、上下文隔离并关闭 Node 集成；不允许新窗口打开外部网页或取得设备权限。全屏切换使用 F11 或“视图 → 全屏”。当前产物未签名，尚非安装器或正式发行版。

自动化启动检查可设置 `MTG_DESKTOP_SMOKE` 为输出 JSON 的绝对文件路径；程序加载窗口并验证本地 `/health` 后记录实际 exe、打包标志、页面地址并退出。这只验证桌面宿主启动，不替代 Forge 对局测试。
