# 战场界面与规则辅助改造

## 目标与设计

基于 D:/MTG-Tabletop 的最新本地提交，在独立分支改造双人牌桌。用户已授权自主实施，不重复询问设计确认。保留手动模式和现有导入、联机、隐藏信息、换备与日志功能。

视觉采用原创石质竞技场背景、暗金边框、青蓝优先级反馈；沿用上下双方战场、底部手牌、侧边堆叠的熟悉组织方式。绘图只承担背景与装饰，按钮、文字和卡牌保持真实 DOM 可交互，不把整个界面烘焙成图片。

规则辅助为服务端确定性子集：明确的支持卡表、费用支付、出地限制、堆叠先进后出、目标与结算检查。支持范围以测试及界面说明为准；未知牌继续走手动处理，不声称完整 MTGA 对局规则。客户端不得决定对手隐藏信息的可见性。

## 实施单元

- [x] 规则：新增独立规则模块、共享协议、服务端入口和行为测试，明确支持与拒绝边界。
- [x] 界面：生成原创战场背景，重构视觉层级、可收起工具、双方生命标识、手牌和阶段操作，接入规则辅助面板。
- [x] 验证：运行规则测试及构建，浏览器检查大厅和实际对战，修复交互与布局问题，更新使用说明和协作约定后提交。

## 验收

可创建房间和进入双人牌桌；原有移动/横置/私密区域仍可用；规则辅助产生可核对的状态变化且拒绝不支持组合；不能凭客户端传值伪造规则结算；英文与中文新增文字一致；窄屏与减少动画偏好可用。未授权自动推送本阶段。

验证记录：15 项规则与双客户端测试通过；TypeScript 检查及 Vite 生产构建通过；浏览器完成大厅、创建房间、抓牌、辅助出地、刷新重连及 390px 窄屏检查。
