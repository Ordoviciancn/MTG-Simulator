# 全面对局客户端重构审计

## 目标与参考边界

采用 Forge 无头核心、Java Bridge、Node 房间服务、React/WebGL 表现层。目标覆盖对局内功能、处理逻辑、操作、视觉与声音反馈、私密同步及恢复；不包含账号、商店、收藏、组牌器、匹配天梯或社交系统。

用户已授权彻底重写。此前规划中“最终保留手动房间”与“只做 CSS 视觉增强”的限制不再适用。旧代码保留到替代实现通过验收，然后移除；不继续扩大单体入口。

参考素材为 2026-09-10 本地录屏和已提供的纸雕场景截图。录制日期不能证明 MTGA 构建版本：参考版本目前标记“未确认”。可以先实施协议与引擎，不阻塞独立工作；宣称逐项完全一致前必须补足版本、未覆盖机制录像和合法声音资产。既有“完整牌面、横置不压缩”要求继续有效，若与参考小窗不同需在视觉矩阵保留明确差异。

## 新模块划分

- Java：MatchRuntime、ChoiceAdapter、ViewProjector、SemanticEventAdapter、StateRecovery；不直接输出 Forge 对象图。
- Node：MatchRegistry、CommandGateway、ForgeTransport、ObserverDispatcher、RecoveryCoordinator；不负责规则结果。
- React/WebGL：AuthoritativeStore、InputMachine、BoardLayout、ChoicePanel、AnimationTimeline、AudioBus；刷新只需快照与待选窗口。
- 协议：Command、ChoiceRequest、ChoiceResponse、GameEvent、PlayerViewSnapshot、Error/Resync 分开，协议版本独立于 Forge 版本。

内部稳定对象 ID 与外部观察者 ID 分离。隐藏对象不能因保留可关联 ID 暴露前后身份；只有规则允许追踪的对象才保持该观察者下的关联。

## 第一阶段：权威基础验收

1. 冻结新协议的 envelope：matchId、协议版本、commandId、玩家身份、expectedRevision；事件包含 eventId、sequence、revision 和经过观察者过滤的对象引用。
2. 建立协议测试：重复同 ID 同载荷返回原回执；同 ID 不同载荷拒绝；旧 revision 拒绝并 resync；另一玩家不能回答 ChoiceRequest。
3. 编译并启动真实 Java Human Match。资源/profile 全部隔离；输入线程不得被正在等待选择的 UI 回调堵住。
4. 稳定输入窗口 ID；控制偏好用每座位 YieldController override，不能只调用不写值的 setYieldPref。
5. 命令行完成起手与出地/施法，记录真实输出；这只是集成测试，不当作游戏演示或完整接通证据。
6. 按玩家生成投影，加入带秘密标记的网络载荷测试；非法动作应被 Forge 拒绝。
7. 第一阶段仅在协议测试、真人 smoke、应用构建通过后提交实现。缺口原样记录，不跳过失败测试。

## 全量验收记录模板

首阶段已验证基础：`pnpm forge:human-smoke` 返回 `humanInputReached:true`、`seatViews:2`、`fullGameVerified:false`。这是使用真实 Human 控制器和真实卡牌数据库的启动集成测试，没有模拟 Forge 输出。命令回执基础已测试并发去重、身份错误、载荷冲突、版本过期和异常后禁止继续执行；尚未接入网页命令路径。

`pnpm forge:human-smoke --spell` 使用固定测试种子，已通过双方保留起手、出山脉、闪电击选择对手、Forge Auto 支付及实际结算；断言对手生命 17、山脉横置、闪电击在坟场且堆叠为空。测试种子只通过进程环境注入，不接受客户端指令设置。该证据覆盖单个真实施法场景，不代表全部费用、响应或完整对局；15 项应用测试和生产构建通过。

新入口 `/?forge` 使用独立 `/forge` 网络协议。`pnpm forge:network-smoke --complete` 已验证两个网络座位从先后手、保留起手、连续出地和闪电击施法，推进到 Forge 的 `gameOver`；重复命令回执一致，另一玩家身份与错误恢复令牌被拒绝，终局后恢复保留玩家生命。16 项应用测试与生产构建通过。浏览器实测完成出地、施法、选目标、自动支付，对手显示 17 生命、己方坟场 1；刷新后保持同一房间和状态。横置仅旋转，牌面比例保持不变。

此入口尚不满足完整发布门槛：复杂选择回调、战斗交互与目标连线、完整事件动画时间轴、声音、旁观者投影、引擎崩溃恢复、所有参考操作逐项对照均未完成。卡组测试使用定向夹具，不代表构筑合法性校验已经实现。英文规则提示保留 Forge 原文；新界面的完整双语字典仍需迁移。

基础战斗阶段：`pnpm forge:network-smoke --combat` 已通过。使用真实灰棕熊与树林牌组，断言新召唤生物不随旧生物攻击、阻挡后双方灰棕熊进入坟场，以及后续未阻挡攻击造成精确 2 点伤害。攻击者、阻挡者及防御目标由 Forge 的 Combat 投影；网页连线跟随卡牌真实位置，不生成规则结果。新增观察者战斗引用过滤测试；17 项应用测试及构建通过。复杂伤害分配和动画时序仍未覆盖。

数值选择阶段：`pnpm forge:network-smoke --x` 已通过。真实 Blaze 选择 X=1，Forge 横置两块山脉并结算 1 点伤害。测试拒绝负数和另一座位作答，数值窗口中开关完全操控均保留原强制选择且不影响对手偏好。原生输入关闭时桥接清理客户端窗口；已接受输入执行异常会中断引擎并冻结房间。18 项应用测试与构建通过。排序、分配及其他复杂模态窗口仍需独立适配。

排序阶段：`pnpm forge:network-smoke --scry` 已通过。真实 Preordain 的两张占卜牌为 Preordain 和 Island，选择不移底并倒转顶牌顺序后，实际抽到 Island。可选选择的 Forge 负数无限制标记转换为明确数量边界；排序结果保留玩家提交的顺序并拒绝重复、缺失或额外索引。19 项应用测试通过，排序控件生产构建通过。原始引擎异常仅写服务端诊断，房间失败消息不包含可能私密的牌名。

每个矩阵 ID 对应：参考构建版本、素材与时间码、前置状态、玩家输入序列、合法动作、Forge 输出、客户端结果、动画/声音事件、是否一致、差异、测试路径和验证提交。无证据即未验证。

语义动画基础阶段：加入有界并行时间轴，按事件序号去重，支持倍速、跳过、后台抑制、减少动态效果和 WebGL 上下文恢复。施法目标、卡牌伤害和控制者由 Java 事件提供，经观察者投影后定位到牌桌对象；生命变化显示浮动数值。24 项应用测试、生产构建及真实 Forge 网络施法测试通过。浏览器双人对局实测在倍速和跳过后对手生命为 17、己方坟场为 1、堆叠为空；山脉宽 92px、高约 128.8px，仅做 90 度旋转。此阶段验证动画控制不会代替规则结算；尚未逐帧验证参考动画一致性，也未完成专属卡牌演出和声音。

最终清理需在新客户端完整核心对局通过后实施：删除旧手动命令、快照猜测特效、死界面与临时默认回调，同时迁移或替换相关测试。新发布入口不得回落旧规则。
