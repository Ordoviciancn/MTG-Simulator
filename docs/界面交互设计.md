# 竞技牌桌交互设计

牌桌保留手动规则裁定。费用、出地次数、目标和结算由玩家负责；服务端同步区域和生命变化，不计算咒语效果。

视觉沿用原创石质竞技场、暗金与青蓝边框、上下双方战场和底部手牌。卡牌选中后在侧栏显示常用移动操作；自己的生命面板提供加减按钮，避免为频繁动作打开完整工具。

完整工具可从顶部打开、从面板内关闭，Escape 收起工具并取消选择。小屏幕将阶段名称独立成行，短桌面视口只收紧间距，不缩小卡牌。手牌超出宽度时保持可横向滚动，避免最左侧卡牌被居中裁切。

验收使用双客户端手动移牌、同回合放置多张地、未支付费用移入堆叠、手动移出后生命不自动变化，以及浏览器桌面与窄屏操作验证。

战场地牌与非地牌统一显示完整牌面，图片等比容纳；横置只旋转 90 度，保留对手的基础朝向，不缩放或裁切。
